# Prompt 05: インライン編集UI、星評価、広めのメモ欄の実装指示

## 実行日
2026-09-20

## 指示文（GitHub Copilot Chatへ投入）

このプロジェクトでは、設計と最終決定は私が行います。
あなたは「実装者」として以下の設計に従ってコードを作成してください。

【制約】
- 設計（型定義や関数の役割）を勝手に変更しないこと
- 新しい外部ライブラリ（アイコンライブラリ等）を追加せず、標準の文字（★ / ☆）またはCSS/SVGで実装すること
- 実装前に不明点や懸念があれば質問すること

【指示内容】
1. 評価（evaluation）のUI改修（星評価コンポーネントの導入）:
   - 従来の `<select>` による評価選択を廃止し、★が5つ並ぶインタラクティブな星評価UIに変更してください。
   - 閲覧モード時: 設定されている評価数（1〜5）に応じて星（★/☆）を表示してください。
   - 編集モード時: 各星をクリック（またはホバー）することで評価（1〜5）を選択・更新できるようにしてください。選択解除（未評価）も可能にしてください。

2. メモ欄（`note`）のUI改修:
   - 読書感想や要約をしっかり書き込めるよう、メモ表示エリアおよび編集時の `<textarea>` の領域を広め（行数 `rows={6}` 以上、またはCSSで十分な高さを確保）に設定してください。

3. 詳細画面 (`BookDetailPage.tsx`) のインライン編集化:
   - 詳細画面の見た目・レイアウト・各項目の配置を維持したまま、その場で編集できる「インライン編集UI」へ改修してください。
   - 閲覧モードと編集モードを同一コンポーネント内で切り替えられるようにします。
   - 閲覧時に表示されているテキスト位置と同じ配置に、編集用の入力要素（`input`, `select`, `textarea`, 星評価）を配置してください。
   - 上部操作エリアに「保存」と「キャンセル」ボタンを配置し、「保存」で `updateBook` を呼び出して表示モードに戻してください。

4. `EditBookPage.tsx` およびルーティングの整理:
   - インライン編集化に伴い、`/books/:id`（詳細画面）の中で編集が完結するように実装してください。
   - `EditBookPage.tsx` が不要になる場合は削除し、`App.tsx` のルート定義から `/books/:id/edit` を除去または `/books/:id` へ統合してください。
