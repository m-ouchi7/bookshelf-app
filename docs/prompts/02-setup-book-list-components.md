## 実行日
2026-09-20

## 指示文（GitHub Copilot Chatへ投入）

このプロジェクトでは、設計と最終決定は私が行います。
あなたは「実装者」として以下の設計に従ってコードを作成してください。

【制約】
- 勝手に設計（型定義やuseBooksの構成）を変更しないこと
- 新しい外部ライブラリを追加しないこと
- UIのレイアウトやスタイリングはシンプルなCSS（またはCSS Modules / インラインスタイル）で実装すること

【指示内容】
1. `src/components/BookCard.tsx` を作成してください。
   - 1冊の本の情報（タイトル、著者、出版社、ステータス、評価、読了日）を表示するカード形式のコンポーネントです。
   - ステータス（未読/読中/読了）を変更できるセレクトボックスまたはボタンを配置してください。
   - 削除ボタンを配置してください。

2. `src/components/BookFilter.tsx` を作成してください。
   - 検索キーワード入力用のテキストボックス（`searchQuery`, `setSearchQuery`）を配置してください。
   - ステータス絞り込み用のラジオボタンまたはセレクトボックス（`filterStatus`, `setFilterStatus`）を配置してください。

3. `src/App.tsx` を修正してください。
   - `useBooks` Hook を呼び出し、`BookFilter` と `filteredBooks` のリスト（`BookCard` の繰り返し表示）を並べてTOPページ画面を構築してください。
   - 検索結果が0件の場合の「対象の本が見つかりません」といった空状態メッセージも考慮してください。
